# Offline Skin Triage Assistant

## Problem
Rural populations lack access to early diagnosis for common skin conditions.

## Solution
A multimodal (voice + image) triage system that:
- Works with low literacy users
- Provides severity-based recommendations
- Runs in low-resource environments

## Features
- Voice input (Hindi/Hinglish ready)
- Image-based analysis
- Risk-aware triage logic
- Confidence-based escalation

## Tech
- Gemma (multimodal reasoning)
- Whisper (speech-to-text)
- Rule-based triage engine

## Impact
Enables frontline health workers to make faster, safer decisions.
